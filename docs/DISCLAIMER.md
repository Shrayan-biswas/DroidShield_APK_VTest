# Responsible Use and Disclaimer

DroidShield is a student project for learning Android application security
testing in authorized environments.

## Authorized Testing
Use DroidShield only with applications, devices, and systems you own or
have explicit permission to test.

## Training Applications
The current documented tests use DIVA, an intentionally vulnerable Android
training application, in a local lab.

## Limitations
DroidShield is a work in progress. Its current tests do not provide complete
Android application security coverage and should not be treated as a
professional security certification or guarantee.

## Data and Evidence
Use synthetic test data whenever possible. Do not publish passwords,
access tokens, personal information, or private application data in reports,
screenshots, logs, or source control.

## Responsible Disclosure
If testing identifies a vulnerability in an application you do not own,
stop testing and report it through the owner's authorized security contact
or disclosure process.

## Disclaimer
The author is not responsible for unauthorized use of this project.
