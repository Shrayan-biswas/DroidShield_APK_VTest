# DroidShield Roadmap

DroidShield is a student Android security testing project. The roadmap
separates completed lab work from planned development.

## Current Progress

- [x] Create repository and project documentation
- [x] Set up Android provider test client
- [x] Inspect DIVA Notes Content Provider configuration
- [x] Test provider query behavior
- [x] Test insert, update, and delete behavior
- [x] Document the test environment and reproduction steps
- [x] Record the exported provider finding

## Next Development Steps

### Phase 1 — Improve Test Client
- [ ] Add clearer test result summaries
- [ ] Separate query and CRUD test cases
- [ ] Handle errors and empty results consistently
- [ ] Record test date and target details

### Phase 2 — Improve Evidence and Reporting
- [ ] Add a reusable finding template
- [ ] Organize screenshots and test evidence
- [ ] Document expected versus actual results
- [ ] Record remediation and retest results

### Phase 3 — Expand Android Security Coverage
- [ ] Review exported activities
- [ ] Review exported services
- [ ] Review broadcast receivers
- [ ] Review application permissions
- [ ] Investigate backup and data storage configuration

### Phase 4 — Validation and Release
- [ ] Repeat tests after changes
- [ ] Review documentation for accuracy
- [ ] Add setup instructions for a fresh lab
- [ ] Tag a documented project release

## Scope

DroidShield is currently a manual testing client and documentation project
for an authorized Android training lab. Planned items are not implemented
or validated until their checklist items are completed.

Testing must remain within applications and devices authorized for use.
