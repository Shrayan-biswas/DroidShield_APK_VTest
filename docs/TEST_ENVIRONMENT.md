# Test Environment

## Purpose
This document records the environment used for the DroidShield Android
security testing lab.

## Host Environment
- Operating system: Kali Linux
- Virtualization: VirtualBox

## Android Test Environment
- Device: Realme Narzo 50 Pro 5G
- Android version: Android 14
- Android SDK level: 34
- Target application: DIVA (Damn Insecure and Vulnerable App)

## Test Scope
Testing focused on the DIVA Notes Content Provider:
- Provider export configuration
- Query operation
- Insert operation
- Update operation
- Delete operation

## Limitations
- Testing was performed in a controlled training environment.
- Results apply to the tested DIVA application and configuration.
- This project does not claim comprehensive testing of all Android
  security weaknesses.

## Reproducibility Notes
Record the following when repeating the tests:
- DIVA APK version or file hash
- Device or emulator details
- Date of testing
- DroidShield test-client version
- Test results and screenshots
